# Skills

Pi skills I use daily, published openly.

A skill is a structured methodology document an AI agent loads on demand — distilled craft knowledge, not prompts. Each one here is synthesized from authoritative sources, checked for provenance, and written to change how an agent actually does the work, not just how it talks about it.

Part of the same system as [signal-profile](https://github.com/scottyha/signal-profile) — encoding intent for AI agents.

## Install

```bash
pi install git:github.com/scottyha/skills
```

Or copy a single skill directory into `~/.pi/agent/skills/`.

## Skills

| Skill | What it is |
|---|---|
| [film-animation](skills/film-animation/SKILL.md) | Film and animation craft — blocking, staging, coverage, lighting, editing and montage, the 12 principles, storyboarding. Synthesized from 19 foundational texts (Lasseter, Murch, Eisenstein, Pudovkin, and more), with provenance checks on every attribution. Use when planning shots, storyboarding, or reviewing video/animation output for craft quality. |

## Scope

The craft corpus is what gets published here. Methodology that carries business differentiation stays private. If you're on pi, these are drop-in skill directories — nothing to configure beyond the install.
