# Game Design — Source Index

The 26 sources behind this skill, what each owns, and the honest caveats. The underlying
corpus (32 reports, ~1.5 MB) sits outside this repo.

**How to cite:** author + work. **Not** page numbers — the majority of page references across
this corpus were unverifiable (print- or lending-restricted sources, image-only PDFs, dead
academic APIs). Semantic Scholar and OpenAlex failed on most runs; Crossref carried the load.

## The named gap — and its verification against the world (2026-10-10)

**In the design literature, no source covers an LLM-narrated, live, in-room, group game.** The
nearest neighbours are Façade (single-player interactive drama) and Generative Agents (an
offline simulation). Everything this skill says about combining *an AI narrator* with *a live
group in a room* is inference from adjacent evidence, not established practice. Treat it as a
hypothesis to test in playtest, and say so when advising.

**That absence was then checked against the world rather than assumed** (three prior-art scans,
filed as `research/27a`–`27c`). What that check found:

- **The four-way intersection is unclaimed.** No shipped product is simultaneously *live +
in-room + group + AI host + persistent world with cross-session player memory.*
- **But its components are taken.** An AI host running games in a venue ships today (Gig Game;
Nightcap/Trivana/QuizVerse) — just per-session. A multiplayer LLM narrator ships (AI Dungeon
multiplayer, since April 2020). A multiplayer AI game master with a persistent *campaign*
ships (Friends & Fables, Old Greg's Tavern, Neural Initiative). Persistent AI characters in a
physical venue ship, early (Aeonia/MMOIRL). Human-vs-AI bluffing is a mass format
(*Human or Not?*, 1.5M+ players, 32% fooled).
- **Two things are genuinely unclaimed:** (1) cross-session memory of the *player* in a shipped
game — persistence is claimed at campaign/world level, but no game demonstrably remembers the
human across separate campaigns; (2) an LLM host for a **physically co-present human group** —
no peer-reviewed study exists (robot game masters did this: AAMAS 2018, HRI 2026).
- **Closest threats:** Aeonia/MMOIRL (persistence axis), DungeonFlux (shape: TV table + phones
+ AI DM for one room — a hackathon prototype that lists cross-session memory as future work),
Gig Game (venue distribution).

**Evidence limits — repeat these when advising.** Confidence is high on the negative, **medium
on completeness.** Semantic Scholar, OpenAlex, and ACM DL all failed or blocked during the scan,
so the academic negative is *"not found," not "proven absent."* It is a point-in-time snapshot.
Never let a client ship a public "world's first" claim without re-running the scan first.

**Practical consequence for design work:** the defensible differentiator is not the AI host —
it is **memory and legibility**. The join no one has is a world that remembers the player and
stays legible to people who weren't there. That is a §26/§27-class problem, not a §6-class one.
